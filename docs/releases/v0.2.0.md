# PastVideo v0.2.0

PastVideo v0.2.0 is the first end-user-oriented Windows binary release. Extract
the main ZIP and run `PastVideo.exe`; no Python, CUDA Toolkit, Rust, or separate
FFmpeg installation is required.

## Highlights

- On-demand local AI setup appears automatically on the first Index action.
- Local NVIDIA GPU indexing remains the default when supported hardware is
  detected.
- Portable CUDA/PyTorch runtime with resumable, verified downloads.
- Built-in model download, copyable direct links for external download managers,
  and selection of an existing `model.safetensors` file.
- English, Simplified Chinese, and Traditional Chinese native UI with automatic
  system-language detection and a live language selector.
- Caption, OCR, and Whisper remain experimental CLI/server features and are not
  shown in the desktop interface or used by desktop search.

## Download

Download `PastVideo-v0.2.0-win-x64.zip`, extract it, and double-click
`PastVideo.exe`. Add folders, then choose **Index new videos**. PastVideo will
guide you through any missing local AI downloads.

The portable runtime is intentionally split into three assets because each
GitHub Release asset must remain below 2 GiB. All archives and the model are
verified before use. See `docs/DISTRIBUTION.md` for component hashes and the
installation design.
